# IT Foundation Learning Hub 🎓

Welcome to the **IT Foundation Learning Hub**, a premium, state-of-the-art interactive educational dashboard designed to provide rigorous computer science and software engineering knowledge. Built with high-performance vanilla web technologies, it features rich visual aesthetics, custom GPU-accelerated inline SVG diagrams, executable code blueprints, and detailed comparative guides.

---

## 🌟 Modern Architectural Features

- **Master 4-Tab Content Switcher**: Every sub-topic card is dynamically segmented into four focused contexts to streamline the learning process:
  - 📖 **Theory**: Rigid, granular definitions, mathematical formulations, and industry standards.
  - 🖼️ **Diagram**: Custom-designed responsive vector SVGs with active CSS glowing animations to visualize technical workflows.
  - 💻 **Deep Dive**: Executable TypeScript/JavaScript code templates, real-world application studies, and side-by-side **Advantages vs. Disadvantages** comparative cards.
  - 🔗 **References**: Curated learning endpoints from authoritative platforms (MDN Web Docs, GeeksforGeeks, IEEE, W3C, Cisco Academy).
- **High-Performance Event Delegation**: Global click listener delegates tab activations, eliminating DOM redundant bindings and guaranteeing ultra-low memory allocations.
- **Vibrant Dark-Light Slate Accents**: Designed with harmonious modern color variables (glassmorphic variables, sleek active borders, and responsive focus bounds).
- **Accessibility & Responsiveness**: Fully compliant with WCAG keyboard access boundaries (`tabindex`, `aria-labels`), optimized for print, and adaptively responsive down to small mobile viewports.

## 🚀 Getting Started & Local Hosting

### Prerequisites
- A modern web browser supporting hardware-accelerated CSS animations.
- A local terminal shell or text editor.

### Local Deployment
1. **Clone/Download** the workspace:
   ```bash
   git clone <repository-url>
   cd "it foundation"
   ```

2. **Boot Dev Server**:
   Host the website locally using standard lightweight servers:
   ```powershell
   # Using Python
   python -m http.server 8080
   
   # Using Node.js http-server (Recommended)
   npx http-server c:\Users\aryan\Desktop\notes\it%20foundation\website -p 8080
   ```

3. **Navigate**:
   Open [http://localhost:8080](http://localhost:8080) in Chrome, Edge, Firefox, or Safari.
